# 李大霄投资战略 · 结构化投资分析框架

本仓库存放《李大霄投资战略》PDF 及基于该书整理的结构化投资分析框架，用于个人研究、投决、跟踪与复盘。

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install streamlit plotly pandas

# 2. 启动量化分析仪表盘
streamlit run app.py
```

浏览器打开 http://localhost:8501 即可看到八维市场温度计仪表盘。

## 文件说明

| 文件 | 说明 |
|---|---|
| `李大霄投资战略.pdf` | 原书 PDF（97 页） |
| `结构化投资分析框架.md` | 基于原书整理的完整分析框架：适配性门槛 → 八维温度计 → 行业/公司/估值 → 投决 → 复盘 |
| `app.py` | **Streamlit 量化分析仪表盘** —— 实时市场温度计 UI |
| `market_engine.py` | 数据引擎 —— 拉取腾讯/东财行情，八维评分，历史记录 |
| `market_temperature.py` | CLI 版温度计（兼容旧用法，`python3 market_temperature.py --batch`） |
| `数据接入指南-a-stock-data.md` | 将 [a-stock-data](https://github.com/tixel0616/a-stock-data)（47 个 A 股数据端点）接入框架的映射指南 |
| `temperature_records.json` | 历史分析记录（运行后自动生成） |

## 使用方式

### 仪表盘（推荐）
运行 `streamlit run app.py`，点击「运行分析」即可获取：
- 实时八维市场温度计
- PE/PB/广度/国债ETF 自动数据
- 手动维度滑块调节
- M 值历史趋势 + 八维雷达图
- 指数行情明细

### CLI 模式
```bash
python3 market_temperature.py          # 交互模式（逐项手动输入）
python3 market_temperature.py --batch  # 批量模式（手动维度默认 0）
```

### 框架研究
1. 阅读 PDF，理解作者的投资理念与历史案例背景。
2. 使用 `结构化投资分析框架.md` 开展研究：先通过适配性门槛，再依次完成市场、行业、公司、估值、投决与跟踪闭环。
3. 框架中的评分权重与阈值为操作性工具，使用前应根据个人约束、资产特征与历史检验校准。
4. 需要真实行情、研报、资金面、公告等数据时，按 `数据接入指南-a-stock-data.md` 接入 a-stock-data 工具包。
