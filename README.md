# 李大霄投资战略 · 结构化投资分析框架

本仓库存放《李大霄投资战略》PDF 及基于该书整理的结构化投资分析框架，用于个人研究、投决、跟踪与复盘。

## 文件说明

| 文件 | 说明 |
|---|---|
| `李大霄投资战略.pdf` | 原书 PDF（97 页） |
| `结构化投资分析框架.md` | 基于原书整理的分析框架：投资适配性门槛、八维市场温度计、公司质量与生命周期评分、三情景估值、仓位与退出规则、投决备忘录及投后复盘 |
| `数据接入指南-a-stock-data.md` | 将 [a-stock-data](https://github.com/tixel0616/a-stock-data)（47 个 A 股数据端点）接入分析框架的映射指南：温度计×数据、公司评分×数据、估值、排雷、调研与监控流程 |

## 使用方式

1. 阅读 PDF，理解作者的投资理念与历史案例背景。
2. 使用 Markdown 框架开展研究：先通过适配性门槛，再依次完成市场、行业、公司、估值、投决与跟踪闭环。
3. 框架中的评分权重与阈值为操作性工具，使用前应根据个人约束、资产特征与历史检验校准。
4. 需要真实行情、研报、资金面、公告等数据时，按 `数据接入指南-a-stock-data.md` 接入 a-stock-data 工具包。
